# Data dictionary: `credit.csv`

Synthetic, seeded data (seed 42, 5,000 rows). No real applicants, no
personal data. Generated by `mlops_credit/data_gen.py`.

| Column | Type | Description |
| --- | --- | --- |
| income | float (GBP/year) | Applicant annual income, log-normal, clipped to 12,000-180,000 |
| loan_amount | float (GBP) | Requested loan amount, log-normal, clipped to 1,000-90,000 |
| credit_history_years | float | Years of credit history, clipped to 0-35 |
| employment_years | float | Years in current employment, clipped to 0-40 |
| debt_to_income | float | Monthly debt payments / monthly income, 0.02-0.90 |
| late_payments | int | Late payments in the last 24 months, 0-12 |
| age_band | category | 18-25, 26-35, 36-50, 51+ |
| default | int (0/1) | Target: 1 if the loan defaulted |

The target is drawn from a logistic model over the features, so risk
rises with debt-to-income, loan-to-income ratio and late payments, and
falls with longer credit history and stable employment.
